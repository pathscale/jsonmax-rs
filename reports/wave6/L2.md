## Changes

- Migrated `crates/jmax-bench/src/parse.rs` from legacy `parts()` tables to native tape words, node/container/depth counters, and decoded storage. Cold parse and schema operations use the current `parse_payload`, `validate_payload`, and `extract_payload` APIs. Warm DOM reuses `DomScratch` through `parse_payload_with_scratch` and recycles documents; warm schema validation calls proof-only `validate_payload_with_scratch`, while extraction uses `extract_payload_with_scratch`. Added borrowed parse, strict schema validate, and strict extraction measurement entry points using borrowed input and reusable scratch.

Escaped strings are resolved from native node/key views; number verification uses raw node spans. No legacy DOM tables or recursive legacy-node emission remain in the bench source.
- Added `wave6_stress_cases(scale)` in `lib.rs` for long unescaped ASCII and Unicode, dense escapes, long even backslash runs, wide objects, reordered fields, and sparse extraction over a large subtree. Existing canonical workload definitions and corpus generation were left untouched.
