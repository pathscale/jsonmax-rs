## Implemented behavior

- All four `RawMasks::finish` implementations publish `delimiter_quote_mask: quotes.delimiter_quote_mask & valid`.
- All four slice classifiers validate length/carry, return immediately for empty input, and route length 64 through a borrowed `&[u8; 64]`. Only lengths 1..63 call tail staging. Array classifiers remain direct.
- NEON raw classification derives all twelve mask fields in one loop over four 16-byte input loads. Structural-only callers delegate to the same fused raw classifier. The comparison reduction shares hoisted weights and uses pairwise widening sums for both halves, with exact address-order bit mapping and native-endian constant construction.
- AVX2 raw classification derives quotes, backslashes and structural classes from the same two 32-byte input loads. Movemasks zero-extend through `u32` before widening.
- All four quote resolvers use word arithmetic: run starts split by even/odd bit position, wrapping additions propagate to odd-run followers, incoming escape carry toggles only the initial run's follower, and a live-length-aligned trailing-one count supplies outgoing parity. There is no per-byte or per-run quote loop.
- NEON prefix XOR uses `vmull_p64` behind `neon,aes`; AVX2/AVX-512 use `_mm_clmulepi64_si128` behind an independent `pclmulqdq` gate on x86_64. The six-shift prefix remains the fallback. Gating uses static target features or std runtime feature detection. Local installed stdarch sources confirm `vmull_p64(u64, u64) -> u128` and its `neon,aes` gate.
- Native scanners expose capability-checked cached bindings. Their constructor chooses both backend and accelerated/portable quote-prefix monomorphization. Calls through the bindings perform neither backend feature detection nor prefix feature detection per block. General public scanner entry points retain independent safety checks.
- UTF-8 complete-slice validation uses the no_std-capable `ps-simdutf8` compat facade for precise error positions. Scalar counting processes eight continuation-byte predicates per SWAR word; it does not decode characters. Existing complete validation/proof and stream scalar counting also use the bulk count.
- String helpers expose SIMD 64-byte quote/backslash/control/non-ASCII masks and cached mask generation. The first-special finder uses bounded SIMD discovery. NEON first-match discovery now reduces comparisons in registers instead of storing a comparison vector to a temporary byte array.
- The new transactional slice decoder validates/counts ordinary runs in bulk, appends them once, and decodes only escape sequences individually. It handles all JSON escapes, UTF-16 surrogate pairs, malformed UTF-8, raw quotes/controls, decoded byte limits, arena limits and absolute offsets. Every error truncates the arena to its original checkpoint. Allocation capacity may grow on a failed operation; prior logical bytes and length are preserved.

## Public APIs for dependent workers

### Dispatch / cursor

`jmax_dispatch::Dispatcher` is an alias of existing `Dispatch`, preserving existing selection/override APIs.

- `pub type ClassifyBlockFn = fn(&[u8; 64], &mut ScanCarry) -> Result<BlockMasks>`
- `Dispatcher::new(input_len: usize, policy: DispatchPolicy) -> Result<Self>`
- `Dispatcher::classify(&self, input: &[u8], carry: &mut ScanCarry) -> Result<BlockMasks>` (existing method, now cached bindings)
- `Dispatcher::classify_block(&self, input: &[u8; 64], carry: &mut ScanCarry) -> Result<BlockMasks>`
- `Dispatcher::classifier(&self) -> ClassifyFn` (existing)
- `Dispatcher::block_classifier(&self) -> ClassifyBlockFn`

`dispatch(...)`, `portable::resolve(...)`, `portable::scalar()` and override selection now return a dispatch containing both cached slice and full-block pointers. Each native scanner also exposes `classify::cached_classifiers() -> Option<(ClassifyFn, ClassifyBlockFn)>` and its root `ClassifyBlockFn` alias. Unsupported backends return `None`/the existing unavailable-backend error; they never issue unsupported instructions.

### UTF-8

Available at `jmax_utf8` root and in `count`; the first two are also re-exported from `validate`:

- `validate_and_count_scalars(bytes: &[u8], base_offset: u32) -> Result<u32>`
- `count_scalars_trusted_utf8(bytes: &[u8]) -> u32`
- `count_continuation_bytes(bytes: &[u8]) -> usize`

The trusted counter requires previously validated UTF-8 and ABI-sized length. It provides no validation proof or unchecked string access; oversized counts saturate. The validating helper checks both length and `base_offset + len` before validation.

### String decoding / encoding

Available at `jmax_string` root and in `masks`:

- `first_escape_or_control(bytes: &[u8]) -> usize` (returns `bytes.len()` when absent; includes mandatory quote escaping)
- `escape_masks_64(bytes: &[u8; 64]) -> EscapeMasks`
- `escape_mask_64(bytes: &[u8; 64]) -> u64`
- `escape_or_control_mask_64(bytes: &[u8; 64]) -> u64`
- `EscapeMasks { quote_mask, backslash_mask, control_mask, non_ascii_mask }`, all `u64`
- `EscapeMasks::escape_or_control(self) -> u64`
- `EscapeMasker::new() -> Self` / `Default`
- `EscapeMasker::classify(&self, bytes: &[u8; 64]) -> EscapeMasks` (cache one per operation)

Available at `jmax_string` root and `unescape`:

```rust
pub fn decode_escaped_slice_into(
    raw_content: &[u8],
    raw_content_offset: u32,
    arena: &mut jmax_buffer::DecodedArena,
    max_string_bytes: u32,
) -> Result<jmax_abi::span::StrRef>;
```

Content excludes wrapper quotes. Returned `StrRef` references `DecodedArena` with the appended span and cooked scalar count. `max_string_bytes` bounds decoded bytes for this string. The syntax worker must enforce its separate raw-token byte limit. Errors are absolute raw-input positions; decoder lexical/limit errors have source `Decode`, UTF-8 errors have source `Utf8`. For a bulk ordinary run, invalid UTF-8 at/before the first excess scalar takes precedence over its byte limit; later malformed bytes do not hide an earlier limit failure. Arena overflow in a raw run points to the first excess raw byte; an escaped scalar maps overflow to its opening backslash.
