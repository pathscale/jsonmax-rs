## Consumer integration: S3 / S4 / S6

`jmax_syntax::block_cursor::BlockCursor` is public and is also re-exported as `jmax_syntax::BlockCursor`. All sixteen frozen methods from CONTRACTS 3.3 are present with their exact argument/return types (the policy and metadata types are imported aliases of the ABI types):

```rust
pub fn new(input: &'a [u8], limits: Limits, numeric: Option<NumericPolicy>,
    dup_owner: DuplicatePolicyOwner) -> Result<Self>;
pub const fn input(&self) -> &'a [u8];
pub const fn offset(&self) -> u32;
pub const fn limits(&self) -> Limits;
pub const fn numeric_policy(&self) -> Option<NumericPolicy>;
pub const fn duplicate_owner(&self) -> DuplicatePolicyOwner;
pub fn skip_whitespace(&mut self) -> Result<Option<u8>>;
pub fn peek_byte(&self) -> Option<u8>;
pub fn advance(&mut self, n: u32);
pub fn expect_byte(&mut self, expected: u8, detail: &'static str) -> Result<u32>;
pub fn scan_string_meta(&mut self, decoded: &mut Vec<u8>) -> Result<StringMeta>;
pub fn scan_key_meta(&mut self, decoded: &mut Vec<u8>, compute_hash: bool) -> Result<KeyMeta>;
pub fn scan_number_span(&mut self) -> Result<Span32>;
pub fn scan_literal(&mut self) -> Result<(TokenKind, Span32)>;
pub fn skip_value(&mut self, decoded: &mut Vec<u8>, current_depth: u16,
    mode: jmax_abi::syntax::SkipMode) -> Result<Span32>;
pub fn finish_eof(&mut self) -> Result<()>;
```

Lexical methods begin exactly at the current byte; callers skip whitespace at grammar positions. Strings/keys consume wrapper quotes; number/literal spans exclude following delimiters; `skip_value` begins before the value and consumes precisely its matching end. `current_depth` counts **ancestor containers**, excluding the skipped value's own opening container. `advance` clamps to the slice's end and does nothing after a sticky lexical failure. Use `expect_byte` for checked punctuation.

S3/S4's direct grammar consumers should continue using the frozen lexical methods and their own object-scope duplicate tables. A lexical key scanner cannot infer object boundaries. `scan_key_meta(..., true)` computes canonical ABI FNV-1a once; `false` returns hash zero and still computes the SWAR head. `DuplicatePolicyOwner::SchemaVm` suppresses syntax duplicate work. `Disabled` is rejected when `limits.reject_duplicate_keys` is true. The grammar-owning `next_event` path described below uses syntax's generation-tagged `KeyTable` and the metadata's already-computed hash. Lexical methods do not independently duplicate a direct consumer's grammar/table.

`SkipMode::StrictValidate` temporarily owns **syntax** duplicate enforcement inside the discarded subtree, including when the outer direct consumer owns duplicates in its Schema VM. It checks all interior JSON/string/number/resource policies but cannot execute schema constraints. S3 must execute applicable schema constraints before choosing an unconstrained syntax-only discard. It never returns a schema proof.

`SkipMode::ValidatedOwner` accepts only an exact `matches_slice` binding under **syntax schema fingerprint 0** and `limits.policy_fingerprint()`. A cursor with `numeric: Some(...)` rejects this mode because the frozen limits fingerprint does not bind NumericPolicy. S3's live schema guard can privately narrow a verified schema-and-numeric capability to syntax scope and construct its authorized cursor with `numeric: None`; this must remain inside its verified guard. Do not pass an arbitrary schema fingerprint through unchanged or claim limits alone cover numeric policy.

## Scanner implementation

- `CursorCache` privately retains active masks, block start/end, outgoing carry, offset, cached Dispatch/full-block function pointer and logically discarded decoded-byte charges. `BlockCursor` retains it across tokens. Complete `SyntaxState` feeds transfer this small cache between lexical calls without constructing a self-referential owner/borrow pair. Dispatch is resolved once per complete parse.
- Refill borrows full `[u8; 64]` blocks using checked slice-to-array references and calls `Dispatch::classify_block`; the final short tail uses `Dispatch::classify`. No whole-input copy, structural-index Vec, token Vec or full-block staging buffer is created.
- Whitespace skips through `(!whitespace_mask & valid_mask) >> relative` and `trailing_zeros`.
- Closing quotes are found through `delimiter_quotes`, with backslash/control/non-ASCII masks restricted to content lanes across blocks. ASCII strings return raw StrRefs with scalar length equal to content length, without byte scanning or arena writes. Unescaped Unicode calls `jmax_utf8::validate_and_count_scalars` on the original bytes and never appends output.
- Escaped strings decode in one transactional traversal: cached classifier pointers discover ordinary runs, UTF-8 validation/scalar counting operates on runs, and each run is appended once. Only backslashes invoke the existing exact escape/surrogate unit decoder; ordinary bytes never walk `StringInput::unit`. ASCII status is accumulated during this traversal rather than rescanning cooked output. Failures truncate the caller's Vec to its original checkpoint; prior bytes are preserved. Raw/cooked string byte limits and aggregate arena limits are checked.
- Numbers discover boundaries and count digit mask bits in the same block traversal. `jmax_number::lex::lex_number` validates once, and active float conversion policy uses `parse_f64`; no separate byte loop recounts digits. Syntax-only large-exponent acceptance remains compatible with the existing lexer-policy exception. Literals compare their exact spelling and check strict JSON value delimiters.
- Query container skipping uses outside-string open/close masks and a bounded tag Vec. The conservative `depth > close_count` rule supplies whole-block net-depth advancement; ordered structural bits still update/check tag identity in unvalidated query blocks so crossed brackets and peak-depth violations cannot hide. Validated-owner skipping can take the actual count-only block jump because its live capability already establishes bracket types and depth, inspecting ordered bits only in candidate terminating blocks. It stops at the first exact matching close, including close-then-open cases.
- Strict discard uses the same scanner and single-check grammar core, retains only escaped keys required for duplicate identity, and materializes no unselected scalar string output. Discarded escaped bytes remain charged across later subtrees/selected strings, so dropping output cannot bypass `max_decoded_bytes`. Private `DiscardScratch` reuses frame and generation-tagged table capacities across successive strict skips on a persistent cursor or SyntaxState.

## Additional jmax-syntax APIs

```rust
BlockCursor::next_event(&mut self, decoded: &mut Vec<u8>) -> Result<ScanStep>
BlockCursor::skip_open_container(&mut self, decoded: &mut Vec<u8>, mode: AbiSkipMode) -> Result<Span32>
BlockCursor::{is_finished, fully_validated, failure, state}
SyntaxState::set_duplicate_owner(&mut self, owner: DuplicatePolicyOwner) -> Result<()>
SyntaxState::duplicate_owner(&self) -> DuplicatePolicyOwner
SyntaxState::fully_validated(&self) -> bool
SyntaxState::skip_open_container(&mut self, mode: AbiSkipMode) -> Result<Span32>
validate_borrowed(input: &[u8], limits: Limits, numeric: Option<NumericPolicy>,
    scratch: &mut Scratch) -> Result<ValidationProof>
validate_borrowed_with_capability<'a>(input: &'a [u8], limits: Limits,
    scratch: &mut Scratch) -> Result<BorrowedValidation<'a>>
```

`next_event` owns JSON grammar and object tables, checks one transition per token, and returns emitted events without an intermediate event collection. Do not mix the grammar-owning interface with a separate lexical/grammar consumer. `skip_open_container` applies immediately after an opening event, commits the matching close while preserving the parent's already-advanced phase/count, and does not emit interior events. `SyntaxState`'s version requires a complete immutable payload. Incremental cursors keep their original resumable event-based skip.

`is_finished` describes grammar EOF. `fully_validated` additionally requires no query-only skips and no outstanding SchemaVm duplicate-policy responsibility. A query-only skip permanently makes the complete traversal conservative until explicit full validation. `finish::finish` revalidates the complete retained slice after any query skip, so `resume::finish` cannot accidentally bless malformed skipped content. No query skip issues `ValidationProof`.

`validate_borrowed` clears caller Scratch, validates and discards one root, then checks EOF and issues a **syntax-only** proof with schema 0 and actual retained decoded length (zero). Duplicate keys, numeric policy and resource limits are checked even for discarded values. Decoded Vec capacity is retained; this generic ABI Scratch does not retain the private typed frame/table allocations between separate validation calls.

`BorrowedValidation<'a>` keeps the original immutable slice borrowed, and has `input()`, `proof()`, `limits()`, `skip_value(&self, &mut BlockCursor<'a>, &mut Vec<u8>, depth)`, and `skip_open_container(...)` methods. Its ABI capability is private, with **no safe bare-token accessor**, because an unbound copyable pointer token could outlive a borrow and later match modified/reused memory. Numeric policies are intentionally excluded from this convenience witness; callers needing numeric/schema capabilities must bind them in their own live guard.

The crate root re-exports `DuplicatePolicyOwner`, `KeyMeta`, `StringMeta`, `ValidationCapability`, and `ValidationProof` in addition to the previous types.

## Grammar and incremental compatibility

`frames::apply_transition` is internal: it calls `machine::transition` once, then privately commits via `frames::apply_parts`. The latter accepts independently borrowed raw/decoded slices, reusable frame/table storage, the checked transition, and an optional cached cooked hash. It does not call transition a second time. Public `machine::transition` keeps its defensive metadata checks.

Complete immutable payloads select the fused scanner in `feed::next`. Incremental `push` still copies explicitly pushed chunks, retains pending-token/tail carry, returns NeedMore until explicit EOF, and retains the first error. Its existing string decoder and atom-bounded numeric publication/error timing are deliberately preserved. The new complete-input numeric path additionally checks the original suffix's legal number boundary. Reset restores Syntax duplicate ownership; schema consumers must explicitly select SchemaVm before parsing each reset input.

## jmax-cursor APIs and behavior

The existing `jmax_cursor::SkipMode::{Strict, Query}` remains source-compatible for owned/incremental traversal and selection. The ABI's three-mode enum is re-exported as **`ValueSkipMode`** to avoid a breaking name collision.

```rust
walk_borrowed(input: &[u8], limits: Limits, mode: SkipMode) -> Result<BorrowedCursor<'_>>
walk_borrowed_with_numeric(input: &[u8], limits: Limits, mode: SkipMode,
    numeric: Option<NumericPolicy>) -> Result<BorrowedCursor<'_>>
select_borrowed<'a>(input: &'a [u8], plan: &SelectorPlan, mode: SkipMode,
    limits: Limits) -> Result<BorrowedSelectedValues<'a>>
select::select_borrowed_with_numeric<'a>(input: &'a [u8], plan: &SelectorPlan,
    mode: SkipMode, limits: Limits, numeric: Option<NumericPolicy>)
    -> Result<BorrowedSelectedValues<'a>>
skip::skip_query(&mut BlockCursor<'_>, &mut Vec<u8>, depth: u16) -> Result<UnvalidatedSpan>
skip::skip_strict(&mut BlockCursor<'_>, &mut Vec<u8>, depth: u16) -> Result<Span32>
skip::skip_validated<'a>(&mut BlockCursor<'a>, &mut Vec<u8>, depth: u16,
    &BorrowedValidation<'a>) -> Result<Span32>
```

Root re-exports include `BorrowedCursor`, both walk constructors, `select_borrowed`, `BlockCursor`, `BorrowedValidation`, both proof/capability types, and DuplicatePolicyOwner. The numeric selection variant is available in `select`.

`BorrowedCursor` methods: `next`, `input`, `raw_bytes`, `decoded_bytes`, `current`, `mode`, `state`, `fully_validated`, `resolve_str`, `skip_current(ValueSkipMode) -> Result<SelectedValue>`, and `skip_validated(&BorrowedValidation<'a>) -> Result<SelectedValue>`. It retains only the borrowed scanner, decoded output, mode and current event. It is complete-input only; use existing Cursor for chunked pushes/suspension.

`BorrowedSelectedValues<'a>` methods: `input`, `decoded_bytes`, `slots`, `fully_validated`, `raw(slot) -> Option<&'a [u8]>`, and `string(slot) -> Option<&str>`. Raw spans resolve into the exact caller allocation; cooked selected escaped strings resolve into the result's arena. It cannot outlive its raw input.

Owned `select::extract` and borrowed selection share a generic selection engine. It preserves terminal-plus-descendant capture and array indexing, and uses skip mode for containers without selector descendants. Strict selection validates skipped interiors; query selection may ignore malformed interior atoms while returning `fully_validated: false`. Missing paths remain None; early query completion retains conservative validation. Existing owned Payload facades preserve their original owners.
