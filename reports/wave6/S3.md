# Wave 6 S3 handoff — packed native DOM

## Status and scope

Implemented in `crates/jmax-dom/**` only; this report is the only write outside that crate. No `cargo` or `rustc` invocation was made. No subagents were used. Compilation, executable tests, allocation counts, and benchmarks remain for the coordinator's Stage 2 barrier.

Read the Wave 6 plan (including Sections 1 and 5), frozen `CONTRACTS.md`, ABI node/buffer/span/syntax definitions, and all five original DOM source modules. No applicable `AGENTS.md` was found in the inspected ancestor paths or owned crate.

**Dependency:** native parsing targets the exact frozen `jmax_syntax::block_cursor::BlockCursor` API. S2's module arrived during final inspection; its constructors, lexical methods, metadata, and `finish_eof` signatures were checked against the DOM calls. Lexical methods do not allocate the cursor's event-grammar vectors, and `finish_eof` is suitable for a consumer that owns grammar itself. The DOM manifest now depends directly on `jmax-syntax`; the former cursor/buffer/string/number direct dependencies are removed, and alloc/std features propagate to syntax.

**Complexity exception requiring coordinator awareness:** safe resolution of an arbitrary public `NodeId(u32)` walks record boundaries to reject keys and extension words. The frozen layout has no header bitmap or node-ID authentication, and an extension word can resemble a header. Constant-time arbitrary-ID membership cannot be guaranteed from that layout alone without another index, a format change, or an unsafe precondition. The implementation preserves correctness: `node`, document `node_*` convenience accessors, and free `node_key_*` helpers are O(preceding records). All navigation from genuine handles, preorder iteration, immediate-child iteration, parent access, raw spans, counts, and string/key references are O(1) per step. `Object::get` is O(members), and `Array::get` is O(index), each jumping whole subtrees. Native encoding should use handles/iterators rather than repeatedly resolving integer IDs.

## Representation and construction

- `pub type Document = TapeDocument`; it is no longer an alias for the mutable legacy ABI document.
- `TapeDocument` privately owns `Payload`, `Vec<TapeWord>`, escaped `Vec<u8>`, node/container/depth counters, `ValidationProof`, and `ValidationCapability`.
- `BorrowedDocument<'a>` privately holds exactly the corresponding borrowed raw slice and final tape/decoded storage/counters/provenance. No input ownership adapter or input copy is made.
- `TapeView<'a>` is a small immutable owner-reference enum, rather than a copy of every slice/counter/provenance field in each node. `Node`, `Children`, `Object`, and `Array` use it for owned/borrowed parity.
- Every native parse path uses direct BlockCursor scanning and one iterative grammar consumer. No event stream, token/index vector, `DocumentParts`, `NodeMeta` array, `Container32` table, or `ValidatedDocument` is constructed along that path.
- Root value header is tape index zero. Native IDs are value-header tape-word indices, not preorder ordinals. Keys are separate records immediately before member values and never count as value nodes.
- All record widths and flag assignments follow the frozen ABI. Compact lengths for literals/numbers are raw token lengths; compact string/key lengths exclude quotes. Extended string/key `raw_len` includes quotes. Numbers retain their original spelling, with full-u32 length storage when extended.
- Containers reserve three words and patch parent/subtree-end and child-count/raw-end words at their matching close. A bounded, reusable `Vec<OpenContainer>` enforces grammar, depth, and immediate child limits.
- The cursor is created with `DuplicatePolicyOwner::Syntax`. Since the frozen `scan_key_meta` API is lexical and has no object-scope parameter, the direct grammar consumer implements that owner's object-scope checking using a reusable open-addressed table keyed by `(object tape index, cooked key hash)`. Hash matches always compare complete cooked bytes, including raw-vs-decoded spelling equivalents. Nested object names do not collide semantically. The table retains all current-parse key entries until reset and is bounded by parsed input/key count, not merely open depth.
- Numeric policy is passed directly to BlockCursor when requested. No extra numeric conversion/cache pass occurs.
- Syntax failure clears partial logical tape/decoded/nesting/duplicate state while retaining allocations. Proof and owner capability are issued only after full EOF validation.

## Public document methods

These methods are present on **both** `TapeDocument` (`Document`) and `BorrowedDocument<'a>`:

| Method | Result / contract |
|---|---|
| `as_tape(&self)` | `TapeView<'_>` sharing immutable owners |
| `root(&self)` | `NodeId(0)` |
| `root_node(&self)` | `Node<'_>` in O(1) |
| `nodes(&self)` | `Nodes<'_>` preorder value iterator; skips key/extension records |
| `raw(&self)` | Original complete `&[u8]`, including surrounding whitespace |
| `tape(&self)` | Immutable `&[TapeWord]` |
| `decoded(&self)` | Immutable escaped-output `&[u8]` |
| `proof(&self)` | Copy of schema-free `ValidationProof` |
| `capability(&self)` | Copy of exact-owner/slice `ValidationCapability` |
| `node_count(&self)` | `usize`, values only |
| `container_count(&self)` | `usize` |
| `max_depth(&self)` | `u16`, scalar roots have depth zero |
| `metadata(&self)` | `TapeMetadata` counters; no parallel node array |
| `node(&self, id)` | Checked `Option<Node<'_>>`; rejects extension/key/sentinel IDs |
| `node_kind(&self, id)` | `Option<NodeKind>` |
| `node_raw_span(&self, id)` | `Option<Span32>` |
| `node_string_ref(&self, id)` | Cooked `Option<StrRef>` for string values |
| `node_key_ref(&self, id)` | Cooked `Option<StrRef>` for member values |
| `node_key_span(&self, id)` | Original quoted-key `Option<Span32>` |
| `resolve_str(&self, reference)` | Bounds/UTF-8 checked `Option<&str>` |
| `resolve_trusted_str(&self, reference)` | Bounds/UTF-8 checked `Result<&str>`; no scalar recount |
| `recycle(self, scratch)` | Return final tape/decoded capacity to `DomScratch` |

`TapeDocument` additionally exposes:

- `payload(&self) -> &Payload`: preserves the supplied owner and visible subrange.
- `to_legacy(&self) -> Result<ValidatedDocument>`: constructs compatibility tables only on demand, clones the immutable payload handle, copies escaped output fallibly, and reindexes IDs into legacy preorder ordinals.
- `into_legacy(self) -> Result<ValidatedDocument>`: constructs compatibility tables on demand and moves payload/decoded storage without copying their bytes.
- `to_validated(&self) -> Result<ValidatedDocument>`: explicit alias of `to_legacy`. There is deliberately no infallible allocating `into_validated` compatibility shortcut.
- `from_validated(document, limits) -> Result<TapeDocument>`: delegates to checked legacy import.

Both document types derive `Clone` and `Debug`. Cloning copies tape/decoded storage, while an owned payload clone retains its original allocation and a borrowed clone retains its original input borrow. Capabilities remain bound to the same raw owner/range.

`TapeMetadata` has public summary fields `root`, `node_count`, `container_count`, `decoded_bytes`, `tape_words`, and `max_depth`. It is intentionally distinct from legacy `DocumentMetadata`; the latter remains re-exported for explicit compatibility code.

## Public shared views, navigation, and scalars

`TapeSource::as_tape(&self) -> TapeView<'_>` is implemented for owned documents, borrowed documents, and `TapeView` itself. It permits generic read-only consumers such as native encoders.

`TapeView<'a>` exposes `raw`, `tape`, `decoded`, `root`, `root_node`, `nodes`, `node`, `proof`, `capability`, `node_count`, `container_count`, `max_depth`, `metadata`, `resolve_str`, and `resolve_trusted_str`. Its by-value accessors retain references for `'a`. Its fields and owner enum are private.

`Node<'a>` (also aliased as `BorrowedNode<'a>`) exposes:

- `id() -> NodeId`, `document() -> TapeView<'a>`, `header() -> TapeWord`, `subtree_end() -> u32`.
- `kind() -> NodeKind`, `raw_span() -> Span32`, `parent() -> Option<Node<'a>>`.
- `children() -> Result<Children<'a>>`, `object() -> Result<Object<'a>>`, `array() -> Result<Array<'a>>`.
- `string_ref() -> Option<StrRef>`, `key_ref() -> Option<StrRef>`, `key_span() -> Option<Span32>`.
- `key() -> Option<&'a str>` and `string() -> Result<&'a str>`: resolve proven record references with **no repeated UTF-8 validation or scalar counting**.
- `raw() -> Result<&'a [u8]>`, `value() -> Result<Scalar<'a>>`, `boolean() -> Result<bool>`.
- `u64()`, `i64()`, `f64()`, and `converted()`: checked opt-in conversions preserving original spelling.

`navigate` free functions are `root`, `node`, `kind`, `raw_span`, `parent`, `subtree_end`, `children`, `object`, `array`, `string_ref`, `key_ref`, `key_span`, `node_key_ref`, and `node_key_span`. Document-taking functions accept `&(impl TapeSource + ?Sized)`. Handle-taking functions operate identically on both document facades.

`Object` exposes `node`, `len`, `is_empty`, `get`, and `iter`. `get` finds the first matching decoded UTF-8 key; member order and allowed duplicates are preserved. `Array` exposes the same methods, with zero-based `get(index)`. Both lengths are immediate-child counts. Iterator construction allocates nothing.

`Nodes`, `Children`, and `Members` implement `Iterator`, `ExactSizeIterator`, and `FusedIterator`; they are cloneable. `Nodes` yields every value in preorder. `Children` yields immediate values and advances using the current value's link word high32. In objects it skips the following key record via `record_words()`. `Members` yields `Member { key: &str, value: Node }`, finding the preceding key at `val_idx - 1` or `val_idx - 3` from the value flags.

`scalar` free functions remain `raw`, `value`, `string`, `boolean`, `u64`, `i64`, `f64`, and `converted`. They accept shared `Node` handles. Integer-spelling restrictions, unsigned-minus rejection, overflow behavior, binary64 finite checks, and source-relative errors remain explicit.

### Trusted string boundary for S5

A public `StrRef` is caller-constructible: even a valid document can be given a reference into the middle of a UTF-8 code point. Therefore the public `resolve_trusted_str(StrRef)` cannot safely call unchecked UTF-8 conversion for arbitrary arguments. It checks bounds/UTF-8 but never recounts Unicode scalars. Internal record resolution is private and unchecked only after a genuine node/member handle establishes provenance.

For native encoding use `view.nodes()` and `node.key()`, `node.string()`, `node.raw()`, `node.header().tag()`, `node.subtree_end()`; or container/member iterators. Those methods provide trusted record access without legacy conversion, integer-ID membership scans, or repeated UTF-8 validation/scalar counting. `Member::key` is likewise already trusted `&str`.

`build` exposes:

```text
parse(Payload, Limits) -> Result<Document>
parse_with_numeric(Payload, Limits, NumericPolicy) -> Result<Document>
parse_into(Payload, Limits, &mut DomScratch) -> Result<&Document>

parse_borrowed_with_numeric(&[u8], Limits, NumericPolicy) -> Result<BorrowedDocument<'_>>
parse_borrowed_with_scratch(&'a [u8], Limits, &mut DomScratch) -> Result<BorrowedDocument<'a>>
parse_borrowed_with_numeric_and_scratch(&'a [u8], Limits, NumericPolicy, &mut DomScratch)
    -> Result<BorrowedDocument<'a>>
parse_borrowed_options_with_scratch(&'a [u8], Limits, Option<NumericPolicy>, &mut DomScratch)
    -> Result<BorrowedDocument<'a>>
from_validated(ValidatedDocument, Limits) -> Result<Document>
from_legacy(ValidatedDocument, Limits) -> Result<Document>
```

Legacy import calls `ValidatedDocument::validate_layout()` before reparsing the retained payload. Mutable foreign tables/proofs never authorize trusted native access. Reparsing applies current limits and discards foreign schema provenance.

`DomScratch` is available at the crate root and in `build`; `build::ParseScratch` is a compatibility type alias. Its methods are:

| Method | Contract |
|---|---|
| `new()` / `Default::default()` | Empty reusable storage |
| `document()` | Last successful owned warm result, if retained |
| `take_document()` | Move out that result; caller may later recycle it |
| `tape_capacity()` | Final tape capacity, including a retained owned result |
| `decoded_capacity()` | Escaped output capacity, including retained owned result |
| `stack_capacity()` | Reusable nesting-stack capacity |
| `duplicate_capacity()` | Reusable hash-table slot count |
| `clear_keep_capacity()` | Reclaim a retained result and reset logical state |
| `clear()` | Alias of `clear_keep_capacity()` |

Warm owned parses recover their previous tape/decoded buffers automatically. Borrowed parses return an independently owned final tape/decoded pair, so the caller must consume `document.recycle(&mut scratch)` before the next parse to reuse those buffers. Live independently owned results cannot share mutable tape storage. Growth remains fallible; repeated equal-or-smaller workloads are designed to require no further DOM allocations after warming. This has source-level/pointer-reuse test coverage, not measured allocator evidence yet.

## Rebuild

- `rebuild::apply(&Document, &[Edit], Limits) -> Result<Document>` addresses native tape IDs. Target validity, duplicates, and overlapping subtree intervals are checked before replacement parsing/output. Assembly reparses into a fresh native tape.
- `rebuild::compact(&Document, Limits) -> Result<Document>` keeps raw scalar/key spelling while removing insignificant whitespace.
- `rebuild::write_document(&(impl TapeSource + ?Sized), &mut dyn ByteSink) -> Result<()>` supports owned documents, borrowed documents, and shared tape views directly. It streams original key/scalar spelling, uses a bounded iterative traversal, and propagates sink errors.

No legacy tables are used by rebuild.

## Integration checklist for C0/S5/S6

1. Compile/test the integrated S2 BlockCursor and native DOM at the Stage 2 barrier.
2. Native facade parse returns `Document` directly; remove old identity `.map(Document::into_validated)` calls. Explicit compatibility export is `to_legacy`/`into_legacy`/`to_validated` and is fallible.
3. Native encoding should consume `TapeSource`/`TapeView` and trusted `Node` methods; do not use legacy `.parts()` or treat native `NodeId` as a preorder ordinal.
4. Migrate callers of the old per-node `DocumentMetadata` view to `nodes()` or handle accessors. `metadata()` now returns counters only.
5. If strict O(1) resolution of arbitrary caller-created integer IDs is mandatory, resolve the frozen-format/index constraint described above; do not replace checked membership with a tag-only test, which could admit extension words into trusted navigation.
